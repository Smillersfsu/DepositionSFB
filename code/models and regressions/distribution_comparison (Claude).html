What “compare two distributions” actually means – three different questions

This document runs three separate tests because “are Ramped and Scarped different” is really three distinct questions, and conflating them is the easiest way to over- or under-claim a result at the defense:

  1. Is the spread different? (Fligner-Killeen) – this is John’s “variation itself is a finding” point, tested directly rather than eyeballed from a boxplot.
  2. Is the whole distribution (shape + spread + location together) different? (Kolmogorov-Smirnov) – this is the literal answer to “what’s the test for comparing two distributions.”
  3. Is the typical value (location/rank) different? (Mann-Whitney U / Wilcoxon rank-sum) – your instinct, and the right test for “which one tends to be higher,” but see the caveat below on what it assumes.

# Shape statistics table, extending the mean/SD/skewness already in
# make_flux_table() (flux_summary.R) with kurtosis -- the piece
# XiaoHang's feedback specifically asked for that wasn't already
# computed anywhere in the pipeline.
shape_stats <- master_tier5 %>%
  group_by(marsh_edge_type) %>%
  summarise(
    n         = n(),
    mean      = mean(Flux, na.rm = TRUE),
    sd        = sd(Flux, na.rm = TRUE),
    median    = median(Flux, na.rm = TRUE),
    skewness  = moments::skewness(Flux, na.rm = TRUE),
    kurtosis  = moments::kurtosis(Flux, na.rm = TRUE),   # RAW kurtosis --
    # moments::kurtosis() does NOT subtract 3, so a normal distribution
    # reads as ~3 here, not 0. (This is the opposite convention from
    # e1071::kurtosis(), which reports EXCESS kurtosis, normal = 0 --
    # if you ever see a kurtosis table with values near 0 instead of
    # near 3, that's a sign it was built with e1071 instead of moments,
    # not that the distribution itself changed.)
    shapiro_p = shapiro.test(Flux)$p.value,
    .groups = "drop"
  )

Step 2: Is the spread different? (Fligner-Killeen)

# Fligner-Killeen is the NON-PARAMETRIC alternative to Levene's test --
# tests equality of variance/spread WITHOUT assuming normality, which
# matters here since Shapiro already rejects normality for both groups
# (shape_stats$shapiro_p above). Given the SD gap already visible in
# shape_stats (Scarped's SD is roughly an order of magnitude larger),
# expect this to come back significant -- report it as a primary
# finding, not a footnote, per John's framing.

fligner.test(Flux ~ marsh_edge_type, data = master_tier5)

    Fligner-Killeen test of homogeneity of variances

Fligner-Killeen:med chi-squared = 19.475, df = 1, p-value = 1.019e-05

Step 3: Is the whole distribution different? (Kolmogorov-Smirnov)

# The literal answer to "what's the test for comparing two
# distributions" -- tests location, spread, and shape jointly, with no
# distributional assumptions. This is the test to cite if XiaoHang or
# the committee asks for one specific name.

flux_ramped  <- master_tier5$Flux[master_tier5$marsh_edge_type == "Ramped"]
flux_scarped <- master_tier5$Flux[master_tier5$marsh_edge_type == "Scarped"]

ks.test(flux_ramped, flux_scarped)

    Asymptotic two-sample Kolmogorov-Smirnov test

data:  flux_ramped and flux_scarped
D = 0.1897, p-value = 0.0002562
alternative hypothesis: two-sided

Step 4: Is the typical value different? (Mann-Whitney U)

# CAVEAT: Mann-Whitney's "which group tends to be higher" interpretation
# technically assumes similar spread between groups. Given the Fligner-
# Killeen result above almost certainly shows spread IS different, a
# significant result here may partly reflect that spread difference
# rather than a pure location shift -- report alongside Step 2, not
# instead of it, and don't claim "Scarped values are simply higher"
# from this test alone if Step 2 was also significant.

wilcox.test(Flux ~ marsh_edge_type, data = master_tier5)

    Wilcoxon rank sum test with continuity correction

data:  Flux by marsh_edge_type
W = 36975, p-value = 0.0002431
alternative hypothesis: true location shift is not equal to 0
# Effect size (rank-biserial correlation) -- Mann-Whitney's p-value
# alone doesn't say how big the difference is, same issue as reporting
# only a p-value for a t-test.
# install.packages("rstatix")  # if not already installed
library(rstatix)

# OPTIONAL, more robust alternative: the Brunner-Munzel test asks the
# same "which group tends to be higher" question as Mann-Whitney, but
# does NOT assume similar spread between groups -- built for exactly
# the situation Step 2 is likely to reveal here. Worth running as a
# cross-check if Mann-Whitney and Fligner-Killeen are both significant,
# since it isolates the location effect from the spread effect that
# Mann-Whitney alone can't fully separate.
# install.packages("brunnermunzel")
library(brunnermunzel)
brunnermunzel.test(Flux ~ marsh_edge_type, data = master_tier5)

How to report this as one coherent result

Given the likely pattern (spread differs a lot, shape/skewness differs, and there may or may not be a clean location shift once spread is accounted for), the honest multi-test story is:

  1. Lead with Fligner-Killeen – Scarped sites show significantly greater variability in sediment flux than Ramped sites. This is the headline result matching John’s “variation itself is a finding” framing.
  2. Follow with Kolmogorov-Smirnov – the two edge types’ overall Flux distributions differ significantly (covers XiaoHang’s literal ask).
  3. Report Mann-Whitney/Brunner-Munzel with the spread caveat stated explicitly – e.g. “Scarped values also tend to rank higher (Mann-Whitney, p = …), though given the spread difference above, a Brunner-Munzel test was used to confirm this isn’t purely an artifact of unequal variance.”

This is also a good complement to the raincloud plot already in RQ1-spatial.Rmd – that plot shows the shape difference visually; this document is the statistical backing for exactly what it shows.

A note on how this fits the classic-tests-vs-GLMM question

This document doesn’t resolve whether to lead the thesis with these classic two-group tests or with the Gamma GLMMs already built across RQ1-3 – that’s the open tension between John’s and XiaoHang’s feedback flagged separately. What it does do: these tests work on the raw two-group comparison (marsh_edge_type alone) without needing the Site/Tran nesting structure, so they’re valid regardless of how that larger debate resolves, and they don’t assume the Gamma link function the GLMMs rely on. Worth having as a model-independent sanity check either way – if a GLMM and Mann-Whitney/KS agree, that’s a stronger result than either alone; if they disagree, that’s worth understanding before the defense, not after.
